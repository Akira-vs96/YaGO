# Состояние реализации YaGo

| Требование | Было при аудите | Сделано | Проверка |
| --- | --- | --- | --- |
| Три активные услуги | API был частичным, старый React не проводил сквозные операции | Такси, доставка и самокаты подключены к PostgreSQL; велосипеды скрыты и отклоняются триггером при создании заказа | Интеграционный smoke и экран услуг |
| Доступ и профиль | Cookie-сессии и роли были в рабочей ветке | Регистрация клиента, вход/выход, CSRF, управление сессиями, ограничения ролей, учебные TOTP и проверка студента | Smoke, браузерный вход клиента и администратора |
| Операции | Основные API были без рабочего интерфейса | Расчёт и заказ такси/еды с маршрутом на карте, история, статусы, отзывы, бронь/аренда самоката, геозона, серверная стоимость | Полные пути трёх услуг в smoke; аренда через браузер |
| История сделки | Цена блюда и тариф уже фиксировались; адреса читались по изменяемой ссылке | Добавлены неизменяемые снимки адресов, координат, названия заведения, стоимости доставки и скидки | Smoke меняет исходные данные и перечитывает заказ |
| Рабочие роли | Кабинеты были неполными | Исполнитель меняет назначенные статусы и передаёт позицию; оператор ведёт заведения, меню, парк, зоны и версии тарифов; администратор управляет ролями/сессиями, смотрит аудит и показатели | Smoke и браузерный кабинет администратора |
| Запуск | Compose запускал только БД | Отдельный Compose-проект с тремя healthcheck-сервисами, lock-зависимости, отдельный seed, автоматические миграции, HTTPS-конфиг | Сборка, чистая миграция и работающий Compose |

Миграции применяются в порядке 001–006; версия схемы после них — 7. Обновление непустой БД требует проверенного backup и `BACKUP_CONFIRMED=1`; существующий исходный volume не очищался. Отдельный seed добавляет вымышленные исторические примеры каждой услуги и не дублирует их при повторе. Схема и объяснение снимков приведены в [DATA_MODEL.md](DATA_MODEL.md).

Пункты недель 9–10 дополнены: успешные и неудачные попытки входа доступны администратору в отдельном журнале; маршрут сохраняется в заказе и остаётся на карте после перезагрузки; при назначении выбирается ближайший свободный исполнитель с известной позицией (если координат нет, используется порядок по ID). Исполнитель может включить непрерывную передачу геопозиции браузера с ограничением частоты запросов. Админка позволяет создавать, читать, изменять и удалять зоны и неиспользованные версии тарифов; использованная версия остаётся неизменяемой. Оценка аренды на клиенте использует тариф, сохранённый при старте аренды.

Проверки выполнены на отдельном учебном PostgreSQL/PostGIS: `npm run lint`, `npm run build`, `docker compose -p yago-weeks-test up -d --build`, `docker compose -p yago-weeks-test exec -T api python smoke_test.py`. Сценарий проверяет регистрацию, CSRF и роли, журнал отказов входа, TOTP, скидку, переходы трёх услуг, идемпотентность, конкуренцию, геопоиск исполнителя, сохранение маршрута, изменение и удаление зон/тарифов, расчёт по сохранённой версии тарифа, PostGIS, неизменность истории и приватность WebSocket. Пустая база успешно дошла до версии 7. В браузере проверены новые элементы кабинета, линия активного заказа после перезагрузки, потеря соединения при остановке API и получение изменённых данных после переподключения, а также передача координат при включении геотрекинга с эмулированной геопозицией. Основная учебная база после резервного копирования обновлена до версии 7; существующие пользователи, заказы и аренды сохранились.

Ограничения для следующего этапа: плитки OSM, поиск Nominatim и маршрут OSRM зависят от внешней доступности и квот; в рабочем HTTPS-окружении нужны домен, секреты и собственные или согласованные endpoints. Рассылка событий в памяти рассчитана на один API worker. Клиентские списки пока показывают первую страницу API без управления пагинацией; ресторанный API ограничен первыми 100 заведениями. Оплата, замок и проверка студента являются явно помеченными учебными эмуляциями. Доставка 2FA-кода не нужна для TOTP, потому что код создаёт приложение-аутентификатор. Внешнее HTTPS-развёртывание не выполнялось без домена и доступа к серверу.
