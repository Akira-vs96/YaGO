## Как читать и передавать материалы

1. Начать с обзора и архитектуры: они объясняют, что уже работает и что проектируется.
2. П3 и П5 использовать единые названия из списка сущностей; связи проверять по ER-модели.
3. При реализации П4 проверять статусы, начисления и обработку ошибок по спецификации, не выводить их из одного общего статуса заказа.
4. Для диплома использовать экономическую главу с сохранением пометок об учебных допущениях и ссылок на источники. Прогнозные значения не заменяют исследование спроса.

Все шесть диаграмм вставлены в документы как PNG: они доступны в обычном Markdown preview без расширений Mermaid. [Галерея рисунков](index.html) открывается в браузере; под каждым рисунком в документах есть ссылка на SVG для увеличения без потери качества. Файлы `.png` подходят для вставки в диплом и презентацию, `.svg` — для масштабирования и печати.

Источником для генерации служат блоки `mermaid` в Markdown, доступные под рисунками в раскрывающемся разделе «Исходник Mermaid». После изменения схем выполните из корня проекта `npm run docs:diagrams`: команда обновит изображения PNG/SVG и галерею в [diagrams](.). Сгенерированные изображения следует обновлять вместе с исходными документами.

## Зафиксированные общие решения

- Текущий стек — Express, React, Leaflet/OSM, Socket.IO, массивы в памяти. Целевой стек по ТЗ — NestJS, React, 2ГИС, PostgreSQL/PostGIS, Socket.IO.
- Общие услуги: `taxi`, `delivery`, `scooter`, `bike`. Старый `food` сопоставляется с `delivery` и `delivery_kind=food`.
- `orders` хранит общий заказ, `rentals` — детали аренды, `vehicles` — технику. Статусы заказа, техники и аренды различаются.
- Деньги рассчитываются сервером в минимальных единицах KZT с сохранением снимка тарифа. Учебные ставки не являются действующими предложениями сервисов.
- Модель определяет 13 основных сущностей; физическая схема, миграции, индексы и подробные классификаторы относятся к неделям 3–4.
- В учебном сценарии замок и телеметрия эмулируются; расчёт суммы не означает интеграцию эквайринга или реальное получение оплаты.
